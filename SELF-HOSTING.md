# Self-hosting priority

Canvas should prove itself against the smallest real environment that contains its own implementation before it is used to visualize a larger external system.

The first source witness is therefore **Canvas projecting the Canvas repository itself**. The first real Board over that source is **Directory Board**.

## Order of evidence

1. **Canvas -> repository field** — project the exact Canvas Git revision into portable grounded Objects + real `contains` Connections.
2. **Repository field -> Directory Board** — add the explicit premise `What exists here, and how is it contained?` and derive deterministic directory arrangement without creating Objects/Connections.
3. **Other Git repositories -> Canvas** — use the same projector and Directory Board derivation unchanged against larger repositories as scale/conformance witnesses.
4. **Additional providers / Board premises** — widen only when a source or question cannot be faithfully expressed by the existing grammar.

A larger repository such as Soveraeign is useful as a later scale witness, but it is not the first product demonstration and must not define the Canvas object model.

## Self-hosting acceptance

For an exact Canvas commit, CI must:

- enumerate the complete tracked Git tree at that commit;
- project every real tree/blob as an ordinary grounded `reference` Object;
- project only Git parent/child membership as `contains` Connections;
- derive Directory Board without duplicating those Objects or Connections;
- persist the Board premise explicitly;
- validate the generated Directory Board document against the portable 0.1 contract;
- resolve every GroundRef to its exact Git object;
- regenerate both repository field and Directory Board byte-for-byte from the same revision;
- render one bounded Directory Board frame with directory/file rows and visible connection geometry;
- publish the `canvas-directory-board` artifact.

The Board is an authored view over the repository field. It is not a second repository and has no authority over Git.
